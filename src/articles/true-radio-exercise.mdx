# 本物のラジオ体操

最近また、夜に寝付けないことが増えた。
気が付くと朝の6時を迎え、外が明るくなっている。
折角なのでテレビでも見て見ようかと、テレビを付けてみたことがある。

民放はどこも情報番組や報道番組をやっているのだが、
NHKのEテレ(旧教育テレビ)はなんと「ラジオ体操」をやっていた。
いや、今回の場合「テレビ体操」と呼ぶべきなのだろうか。
普段は声だけのインストラクションだが、
今日は「その身体はラジオ体操では作れないだろう」という
引き締まりすぎた身体の男女3人が、
お手本として体操をやってくれている。

運動や肉体労働とは無縁の人生を送ってきた私にとって、
ラジオ体操の記憶は20年以上も昔の小学生の夏休みまで遡る。

毎回、起きているのか寝ているのか分からない状態で臨んでいたラジオ体操だが、
子供のころの記憶というのは、20年経っても案外覚えているもので、
メロディーを聞くと次にどんな運動をすればいいのか、何となく分かる。

しかも今回は、テレビの映像付きなので、
いつものラジオの「両手を上にあげて大きく背伸びの運動」のような大雑把な説明ではなく、
明確な正解を見ながら体操が出来る。

…見ていて、何か違和感を感じた。
自分が子供のころにやっていた体操よりも、
だいぶ全身を使って運動している。
ラジオ体操第一、一番最初の足を曲げ伸ばしする運動の時点で、
足を斜めに開いているという違いがある。

なるほど、屈伸のように曲げ伸ばしするのではなく、
少し横に足を開いて曲げ伸ばしすることで、
力が左右に抜けるのである。
それが、左右に振っている手の運動と呼応するという仕組みになっているのである。
初めて知った。

その後も、ねじる運動のとき、
上半身だけでなく下半身も動かしていることに気づいた。

ラジオ体操第二に至っては、自分がやっていたものよりも、
幾分激しい運動に思えた。
そういえば、ラジオ体操第二は
児童には激しすぎる運動だという話を聞いたことがある。
その話を聞いた時は、「子供をなめるな」と思ったものだが、
これを見ると納得だ。

その一番の理由として、
全体的につま先立ちになる場面が多いのだ。
全員がやってる感だけで行っていた、
力こぶのポーズを行う運動も、
お手本を行う体操のプロ達は、
直前につま先立ちをして、
大きく勢いをつけて行っていた。

深呼吸前の足の曲げ伸ばしも、
第一とくらべると、かなり激しい。

整体に行ったとき「運動不足解消には、ラジオ体操をやるといいですよ」といわれ
「30代をなめるな」と思ったものだが、
確かにこれを毎日全力でやると、いい運動になる気がする。

しかしだ。
この事実に気づいている日本人がどれだけいるだろうか。
どうして、日本人はこうもラジオ体操を舐めているのだろうか。

その理由は、あの夏休みのラジオ体操にあると、私は踏んでいる。

そもそも、お手本となるのが、
近所の普段運動をしているのかどうかもわからない、
早起きが得意という理由だけで
そこに来ている爺さんや婆さんである。
恐らく、彼ら彼女らは、それぞれの運動に
どういった意味があるのかすら理解していない。
そんなお手本の動きを真似したところで、
本物のラジオ体操にはならないのである。

そして何より、子供たちの圧倒的モチベーションの低さである。
小学校の期間である7歳から12歳というのは、人生で一番準備運動がいらないなのである。
あの年齢の子供たちはラジオ体操なんかしなくても、
無限の体力があるし、次の日に体を痛めたりなんかしないのである。

そんな時期に、せっかくの夏休みなのに、普段よりも早い時間に起こされて、
爺さん婆さんのお手本の元、体操をさせられるのである。
これでまじめにやるほうがどうかしている。

さらに、高学年になると、冷笑が猛威を振るうようになる。
真面目にやらないことを美徳とする文化が広まるのだ。
両足飛びなんて地面から浮くか浮かないかギリギリの高さでしか飛ばないし、
身体をそらす運動も、一番地面と垂直を保っている奴が偉いのである。

そんな適当な運動に対して、大人たちが指導をしているのを見たことがない。
全く体操をせずにお喋りしている子供にはさすがに注意をしていたが、
体操のクオリティチェックが入っている場面を見たことがない。
なんとなく、ラジオ体操っぽい動きをしていればセーフという空気が蔓延している。

そういったなぁなぁの大人と子供の関係により、
「ラジオ体操は大した運動ではない」
「ラジオ体操で疲れる訳がない」
といった共通認識が全国的に形成されているのである。

しかし、私はいま知ったのである。
ラジオ体操を本気でやると、結構疲れそうであるということを。

ちなみに、そんなことを考えていたら番組が終わったので、
私は一切体を動かすことはなく、そのままテレビを切った。
あの後調べたところ、毎週月曜の朝6時にNHKを付けると、
ラジオ体操をテレビでやっているらしい。

ちなみに、この文章を書いている今の時間は、月曜の朝の5:27である。
寝る支度をしていれば、ちょうどラジオ体操が始まる時間だ。

本気でやってみて、どれくらい疲れるのか試してみよう。

(終)
