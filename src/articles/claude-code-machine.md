## Claude Code Remote Control

先日、 Claude Code に Remote Control という機能が追加された。
簡単に言うと、ローカル PC で走る Claude Code に外部から指示を出す機能だ。

シンプルなユースケースだと、時間のかかる処理をローカルPCでやらせておく。
たまに承認が必要になる時は、スマホやラップトップからOK/NG を押すといったことが考えられる。

今まで、Web 上で実行するときは Claude が用意したサンドボックス環境でしか実行が出来なかった。
なので、通信の自由もなければ、MCP や周辺ツールといった便利な機能が根こそぎ奪われた状態でしか実行できなかった。

この機能によって、いつもの Claude Code に外部から指示を出せるようになるのである。

もう少し手の込んだユースケースだと、
エラーを通知する Slack チャンネルに bot を常駐させ、
エラーが飛んで来たら、bot が Remote Controle に対して原因調査および修正の指示を出す。
万が一、夜中にエラーが発生しても、朝起きたら既に Pull Request が出来上がっているという寸法だ。

今までの指示がないと動かなかったものと違い、自律的に動くツールになる。
まるで、スカイネット誕生前夜を思わせる。
